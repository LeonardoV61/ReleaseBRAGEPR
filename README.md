# Release BRAGEPR

### Atividade da matéria de BRAGEPR sobre release, onde será feita uma simulação de projeto de um sistema com tela de login.

### A aplicação WEB simulada foi construída com html e javascript sem recursos de css ou preocupação com design.

***A funcionalidade completa tem 4 páginas html:***
1. Uma página de login (index.html);
2. Uma para mensagem de erro (msg.html);
3. Outra simulando um usuário administrador (pg001.html);
4. E, por fim, uma de usuário operador (pg002.html).
